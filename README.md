## Game 2D

## How to install this project

# Step 1
Run this command in your terminal to copy the repo
```
git clone https://github.com/Tman360A/game-2d.git
```
# Step 2
Open the terminal in the projects directory and run this starting command
```
cargo run
```

## Keybinds
* use ASWD to move
* use SPACE to jump
* use TAB to change characters
* use ESC to quit the program
